# Conventions de code (projets JS / Phaser)

## Fichiers et dossiers
- Classes (scènes, entités) : `PascalCase.js` (`GameScene.js`, `Player.js`).
- Autres fichiers JS : `camelCase.js` (`constants.js`, `helpers.js`).
- Dossiers : minuscules (`scenes/`, `entities/`).
- Assets (images, sons, maps) : `snake_case`, sans espaces, accents ni majuscules (`player_1_idle.png`).
- Fichiers de scène suffixés `Scene` (`MenuScene.js`).

## Code
- Classes : `PascalCase` (`class Player`).
- Variables et fonctions : `camelCase` (`playerSpeed`, `loadWorld()`).
- Constantes : `MAJUSCULES_SNAKE` (`PLAYER_SPEED`, `SCENES.HUB`).
- Code en anglais ; commentaires et commits en français.
